# Nezeriya Site

Static multi-page company website (HTML/CSS/JS, no build step). Deployed on Render as the static site `nezeriya-site` from this branch.

Pages: `index.html`, `wallet.html`, `card.html`, `tariffs.html`, `security.html`, `company.html`, `faq.html`, `contacts.html`, `data.html`, `privacy.html`.
Placeholders still waiting for facts are marked with `class="todo"`.
